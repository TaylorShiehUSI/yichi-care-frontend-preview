# 憶起照顧 7A2 擴充功能安裝與使用

1. 下載並解壓 [Chrome 擴充功能 v0.3.4](./yichi-care-7a2-bridge-0.3.4.zip)。
2. 在 Chrome 開啟 `chrome://extensions`，啟用開發人員模式，選「載入未封裝項目」，再選含有 `manifest.json` 的資料夾。若已安裝 7A1 擴充功能，將新版檔案覆蓋原資料夾後按「重新載入」。新版同時支援 7A1 和 7A2。
3. 使用同一個 Chrome 設定檔與自己的 Google 帳號，開啟 [指定 NotebookLM 筆記本](https://notebook.google.com/notebook/8242fbbf-ed59-4541-93db-4e3c7eb4d275)。只保留一個該筆記本分頁。更新擴充功能後請重新整理筆記本與 7A2 頁面。
4. 回到 [7A2 首頁](./)，輸入問題並按「查詢」。最新一題的 NotebookLM 原答和可取得的引用會顯示在同一欄。
5. 展開引用查看引文。圖卡請在 NotebookLM 的原回答中查看。引用讀取不完整時仍會顯示原答。

NotebookLM 保留聊天歷史，可能參考前文。請避免輸入姓名、電話、身分證字號等個人資料。
